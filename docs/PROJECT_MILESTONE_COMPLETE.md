## 附录: 快速参考

### 启动服务
```bash
# 启动 API 服务器
./target/release/browerai-api-server

# 执行模型评估
python3 training/pipelines/complete_system.py

# 运行测试
cargo test --all
```

### API 调用示例
```bash
# 框架检测
curl -X POST http://localhost:8080/detect/framework \
  -H "Content-Type: application/json" \
  -d '{"html": "<html>...</html>"}'

# 混淆检测
curl -X POST http://localhost:8080/detect/obfuscation \
  -H "Content-Type: application/json" \
  -d '{"js": "var a=function(){...}"}'
```

### 常见问题
- Q: API 启动失败？
  A: 检查端口 8080 占用，或查看日志 `RUST_LOG=debug`

- Q: 模型评估超时？
  A: 增加虚拟机内存或使用并发处理

- Q: 框架检测准确率低？
  A: 收集更多样本或微调特征提取
