## 🧠 核心设计原理

### 1. 48维特征向量设计

```
┌────────────────────────────────┐
│ 48维特征分布                    │
├────────────────────────────────┤
│ [0-9]   : HTML指标 (10维)      │
│ [10-17] : CSS指标 (8维)        │
│ [18-27] : JS指标 (10维)        │
│ [28-35] : 页面结构 (8维)       │
│ [36-42] : 设计风格 (7维)       │
│ [43-47] : 复杂度指标 (5维)     │
└────────────────────────────────┘

每个维度都是标准化的 [0, 1] 范围
```

**优点**:
- ✅ 标准化: 统一的范围和单位
- ✅ 完整: 覆盖网站所有主要方面
- ✅ 可解释: 每一维都有明确含义
- ✅ 稳定: 无NaN/Inf值

### 2. 256维潜在空间

```
编码过程:
features (48D) 
  ↓ 线性变换 (48×256矩阵)
  ↓ ReLU激活
  ↓ 意图嵌入 (+10%)
  ↓ 风格嵌入 (+10%)
latent (256D)
  ↓ 单位正规化
完成！
```

**特性**:
- 可学习的权重矩阵
- 意图感知嵌入 (blog, ecommerce等)
- 风格感知嵌入 (modern, minimal等)
- 单位球面正规化

### 3. 代码生成策略

```
潜在向量分割:
latent[0:85]    → HTML骨架生成
latent[85:170]  → CSS规则生成
latent[170:256] → JavaScript逻辑生成

使用潜在向量的不同部分控制
不同类型代码的生成参数
```

### 4. 质量验证系统

```
三维质量评分:
├─ HTML质量: 标签完整性、平衡性
├─ CSS质量:  规则完整性、选择器正确性
└─ JS质量:   函数完整性、语法正确性

总体评分 = (HTML + CSS + JS) / 3
范围: 0.0 ~ 1.0
```

## 📖 使用快速参考

### 30秒入门

```python
from model_library import ModelLibrary

# 初始化
library = ModelLibrary()

# 处理网站
result = library.process_website({
    'html': '<h1>Hello</h1>',
    'css': 'h1 { color: blue; }',
    'scripts': 'console.log("Hi");',
    'framework': 'react',
    'intent': 'blog',
})

# 查看结果
print(f"质量: {result['quality_scores']['overall_quality']:.1%}")
```

# 单个网站
